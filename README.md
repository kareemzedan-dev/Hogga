# حُجّة — hogga

> منصة رقمية متكاملة للخدمات القانونية في سلطنة عُمان

---

## نبذة عن المشروع

**حُجّة** منصة رقمية تعمل كطرف ثالث لربط العملاء بالمحامين، بهدف تنظيم تقديم الخدمات القانونية وإدارة الطلبات والاستشارات والقضايا من خلال بيئة رقمية متكاملة.

تتيح المنصة للعملاء الوصول إلى المحامين المتخصصين بسهولة، وتوفر للمحامين نظامًا لإدارة طلباتهم القانونية وتنظيم أعمالهم. وتعمل الإدارة على الإشراف الكامل على جميع العمليات لضمان جودة الخدمة وتنظيم البيانات.

## هيكل النظام

يتكون النظام من ثلاث طبقات رئيسية:

```
1. لوحة الإدارة   (Admin Dashboard)
2. لوحة المحامي   (Lawyer Dashboard)
3. واجهة العميل   (Client App)
```

---

## وحدات النظام

### 1. لوحة الإدارة (Admin Dashboard)

#### إدارة المحامين
- إضافة محامين جدد وتوثيق حساباتهم
- تصنيف المحامين حسب التخصص
- تفعيل / إيقاف الحساب
- متابعة الأداء وعدد الطلبات

#### إدارة العملاء
- عرض وتعديل بيانات العملاء
- متابعة الطلبات المقدمة
- عرض سجل الخدمات القانونية

#### إدارة الطلبات القانونية
حالات الطلب: **جديد ← قيد المراجعة ← قيد التنفيذ ← مكتمل ← مغلق**

- استقبال ومراجعة الطلبات
- تصنيف الطلب وتوجيهه للمحامي المناسب
- متابعة حالة الطلب

#### إدارة القضايا
- إنشاء قضية من طلب مقبول
- ربط القضية بالمحامي والعميل
- تسجيل الجلسات والملاحظات القانونية
- متابعة مراحل القضية

#### إدارة المستندات
- رفع وتصنيف الوثائق
- ربط الملفات بالقضايا
- إدارة صلاحيات الوصول
- الصيغ المدعومة: PDF، صور، مستندات نصية، مرفقات قانونية

#### إدارة الحجوزات
حالات الحجز: **جديد ← مؤكد ← مكتمل ← ملغى**

- عرض المواعيد المتاحة لكل محامٍ
- حجز موعد استشارة (حضوري / مكالمة / أونلاين)
- تحديد مدة الجلسة
- إدارة جدول المواعيد

#### إدارة البنرات الإعلانية
- إضافة بنرات جديدة بصور وروابط
- تحديد مدة ومكان الظهور (الرئيسية / المحامون / الخدمات)
- تفعيل/إيقاف الإعلانات
- متابعة الأداء وعدد مرات الظهور

#### إدارة الفواتير والأرباح
- إنشاء الفواتير وتتبعها
- متابعة المدفوعات والتسويات المالية
- تقارير أرباح كل محامٍ
- تصدير بصيغ PDF و Excel

#### التقارير والإحصاءات
- عدد الطلبات القانونية / القضايا النشطة / الحجوزات
- أداء المحامين
- نشاط النظام خلال فترة زمنية محددة
- تصدير PDF و Excel

---

### 2. لوحة المحامي (Lawyer Dashboard)

- **إدارة الطلبات**: استقبال، مراجعة، قبول/رفض، تحويل إلى قضية
- **إدارة القضايا**: عرض، تحديث الحالة، تسجيل إجراءات وجلسات
- **إدارة العملاء**: عرض بيانات العميل وسجل الطلبات
- **المحفظة والأرباح**: عرض الأرباح، العمولات، طلب سحب
- **إدارة المستندات**: رفع، تصنيف، مشاركة مع العميل
- **إدارة الحجوزات**: تحديد أوقات العمل، قبول/رفض، تعديل المواعيد
- **الإشعارات**: طلبات جديدة، حجوزات، تحديثات القضايا، مستندات، تذكيرات

---

### 3. واجهة العميل (Client App)

- تصفح المحامين والتخصصات
- إنشاء طلب خدمة قانونية (نوع الخدمة، وصف المشكلة، المستندات)
- حجز استشارة (اختياري)
- متابعة حالة الطلب والقضية
- عرض المستندات والفواتير

---

## Workflow الكامل

```
1. تسجيل المستخدم
        ↓
2. إنشاء طلب خدمة قانونية (نوع + وصف + مستندات + تخصص)
        ↓
3. مراجعة الطلب من الإدارة + توجيهه للمحامي المناسب
        ↓
4. استلام الطلب من المحامي (قبول / رفض / طلب معلومات إضافية)
        ↓
5. [اختياري] حجز استشارة مع المحامي
        ↓
6. فتح قضية قانونية
        ↓
7. متابعة القضية (تحديث الحالة + مستندات + جلسات)
        ↓
8. إغلاق القضية وأرشفتها
```
